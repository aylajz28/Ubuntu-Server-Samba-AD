# Ubuntu Server 24.04 – Samba Active Directory 🐧

## About This Project

This repository contains a practical assignment completed as part of my **Network Computer Systems Administration (ASIR)** studies.

The main objective was to install, configure and administer an Ubuntu Server environment, using Samba to set up an Active Directory Domain Controller.

The project was completed in a virtualized environment using Oracle VirtualBox, with an Ubuntu Server machine and a Windows client.

## Technologies & Tools

- **Ubuntu Server 24.04** – Linux server installation and administration.
- **Samba Active Directory** – Domain controller configuration and management.
- **DNS** – Domain name resolution and configuration.
- **Kerberos** – Domain authentication.
- **Netplan** – Network interface and IP configuration.
- **Linux Command Line** – Server administration and troubleshooting.
- **Oracle VirtualBox** – Virtual machine management.
- **Windows Client** – Domain connectivity and authentication testing.

## What I Did

During this practice, I worked on the following tasks:

- Installed and configured Ubuntu Server in a virtual machine.
- Configured network interfaces and static IP addressing using Netplan.
- Installed and configured Samba as an Active Directory Domain Controller.
- Configured and checked DNS and domain authentication services.
- Used `samba-tool` commands for domain administration.
- Created and managed domain users and groups.
- Configured shared resources and access permissions.
- Connected a Windows client to the Samba domain.
- Tested network connectivity and domain authentication.
- Identified and troubleshot configuration errors during the installation and setup process.

## Troubleshooting

One of the main challenges during this practice was configuring Samba correctly as a domain controller.

I encountered problems during the domain provisioning process and had to review the configuration and service status.

To resolve these issues, I checked the Samba configuration, stopped conflicting services and repeated the necessary configuration steps.

This process helped me better understand how Linux services interact and how to diagnose problems in a server environment.
